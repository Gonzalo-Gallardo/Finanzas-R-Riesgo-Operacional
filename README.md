# Finanzas R - Riesgo Operacional

## Descripción del proyecto

Proyecto desarrollado en el marco del Diplomado de Análisis de Datos, orientado a la aplicación de herramientas de programación y análisis de datos en el ámbito de Riesgo Operacional.

El proyecto busca desarrollar una herramienta que permita apoyar la revisión y priorización de riesgos y controles, considerando variables asociadas al diseño y ejecución de los controles.

## Objetivo

Desarrollar una solución aplicada a Riesgo Operacional que permita estructurar, analizar y priorizar riesgos y controles, facilitando la identificación de situaciones que requieran revisión y apoyando el proceso de análisis mediante herramientas de programación y análisis de datos.

## Entrega 01 - Definición del problema

La primera entrega presenta la definición y estructuración del problema que será abordado durante el proyecto.

El análisis considera la relación entre los riesgos operacionales y sus respectivos controles, incorporando elementos relevantes para su evaluación, tales como:

- Riesgo asociado.
- Control asociado al riesgo.
- Descripción y ejecución del control.
- Frecuencia de ejecución.
- Tipo de control: manual o automatizado.
- Existencia de planes de acción.
- Criterios para la revisión y priorización de controles.
- Matrices de riesgo para representar su nivel de exposición.

El desarrollo de esta primera etapa establece las bases para las siguientes entregas, en las cuales se incorporarán herramientas de programación y análisis de datos.
